# 方案一动机实验结果分析报告

## 1. 实验概况

- 主结果目录：`program1_20260822_222429`
- 数据集：SIFT100M，128 维 uint8 向量
- 索引：schema 16；baseline 和 solution 使用相同 index prefix 与 build fingerprint
- Baseline：`coupled`，在 ACK 前完成全局搜索、候选读取和反向边维护
- 方案一：`decoupled`，Stage1 完成后 ACK，Stage2 后台完成全局 refinement
- 性能负载：insert-only，16 个客户端线程，预热 128 次、测量 1000 次
- 质量负载：插入 1000 个新节点，并查询全部 1000 个新向量
- 重复次数：1

本轮所有关键有效性检查均通过：互斥关键路径计数有效；Stage1-only 查询位于人工延迟窗口内；最终质量查询前 Stage2 已达到 durable watermark；Stage2 延迟直方图和 locality 计数均获得非零样本。

## 2. 核心结论

1. **同步更新关键路径中，86.29% 属于可以移到 Stage2 的全局工作。** 其中全局 continuation 占 68.59%，最终候选快照读取占 0.57%，远程反向边更新占 17.13%。本地 Stage1 搜索只占 12.91%。
2. **方案一将前台插入吞吐提高 6.28×。** 吞吐从 344.42 ops/s 提高到 2163.44 ops/s；平均 ACK 延迟下降 84.12%，P99 下降 92.04%。即使把 Stage2 drain 算入，durable 吞吐仍提高 5.06×。
3. **Stage1-only 的整体 Top-10 结果与最终索引高度一致。** Stage1 与 Stage2 完成后的 Top-10 结果重合率为 97.02%，即平均每个查询只有约 0.30/10 个结果发生变化。不过，严格的新节点 self-hit@10 从 Stage1 的 85.9% 提高到最终的 100%，说明少部分新节点在 Stage1 期间仍存在临时可达性不足。
4. **精度牺牲持续时间较短。** Stage2 平均完成延迟为 136.42 ms，P99 所在直方图区间上界为 512 ms，且没有样本超过 30 s；1000 次前台测量结束后的全部 backlog 在 112.01 ms 内排空。
5. **迁移明显改善了新插入节点的物理局部性。** 若保持 Stage1 home，跨分片边比例为 17.93%；采用最终迁移 home 后降至 14.30%，相对减少 20.27%，绝对下降 3.63 个百分点。

## 3. 动机实验一：同步更新关键路径分解

### 3.1 可直接绘制的互斥堆叠数据

| 阶段 | 每次插入平均时间 | 关键路径占比 | 是否留在前台 |
| --- | ---: | ---: | --- |
| 本地 Stage1 搜索 | 5.889 ms | 12.91% | 是 |
| 跨分片全局 continuation | 31.300 ms | 68.59% | 移至 Stage2 |
| 最终候选快照读取 | 0.259 ms | 0.57% | 移至 Stage2 |
| 远程反向边更新 | 7.816 ms | 17.13% | 移至 Stage2 |
| 最终 prune | 0.183 ms | 0.40% | Stage2 后缀 |
| 节点分配与写入 | 0.105 ms | 0.23% | Stage1 必需 |
| 元数据与其他 | 0.079 ms | 0.17% | 其他 |
| **合计** | **45.630 ms** | **100%** | — |

可以移出 ACK 关键路径的三项为：

```text
全局 continuation 31.300 ms
+ 最终候选快照读取 0.259 ms
+ 远程反向边更新 7.816 ms
= 39.374 ms，占同步关键路径 86.29%
```

因此，方案一的核心动机得到了直接支持：同步模式不是慢在本地 Stage1，而是慢在 Stage1 之后的跨分片全局 refinement 和远程图维护。

### 3.2 “纯 RDMA”口径说明

报告同时保留了一个保守的显式 read/reverse 子计数：平均 11.229 ms，占 24.61%。它不能代表全部 RDMA 相关开销，因为完整 global continuation 中还包含批量远程图读取、远程向量获取、等待、评分和搜索控制，而旧的细粒度 read 子计数没有覆盖这些边界。

因此论文图建议标题使用：

> Coupled update critical-path phase breakdown

其中将 68.59% 的部分标为 `Cross-shard global continuation` 或 `RDMA-driven global refinement`，不要直接标成 `pure RDMA transfer`。远程反向边更新可以单独画成另一段。

推荐论文表述：

> In the coupled design, 86.3% of the update critical path is spent after local Stage1 on cross-shard global continuation, final candidate materialization, and remote reverse-edge maintenance. Deferring these RDMA-driven global operations to Stage2 removes 39.4 ms from the foreground path on average.

## 4. 动机实验二：方案一的更新性能

| 指标 | Coupled baseline | Two-stage | 改善 |
| --- | ---: | ---: | ---: |
| 前台插入吞吐 | 344.42 ops/s | 2163.44 ops/s | **6.28×** |
| 含 Stage2 drain 的 durable 吞吐 | 344.40 ops/s | 1741.45 ops/s | **5.06×** |
| 平均 ACK 延迟 | 45.97 ms | 7.30 ms | **下降 84.12%** |
| P50 ACK 延迟 | 23.11 ms | 6.01 ms | 下降 74.01% |
| P95 ACK 延迟 | 178.90 ms | 16.05 ms | 下降 91.03% |
| P99 ACK 延迟 | 272.48 ms | 21.68 ms | **下降 92.04%** |
| P99.9 ACK 延迟 | 360.90 ms | 25.82 ms | 下降 92.85% |

结果与关键路径分解一致：coupled 平均关键路径为 45.63 ms，客户端观测平均延迟为 45.97 ms；将其中 39.37 ms 的全局后缀移出前台后，方案一平均 ACK 延迟降至 7.30 ms。

应同时报告两种吞吐口径：

- 6.28×：用户看到的 Stage1 ACK 吞吐提升；
- 5.06×：把测量结束后的 Stage2 排空时间也计入后的 durable 吞吐提升。

## 5. 动机实验三：Stage1-only 短期质量

| 指标 | Stage1-only | Stage2 完成后 | 差异 |
| --- | ---: | ---: | ---: |
| 新节点 self-hit@10 | 85.9% | 100% | 下降 14.1 个百分点 |
| 与最终 Top-10 的结果重合率 | 97.02% | 100% 参考 | 仅 2.98% 结果变化 |
| 查询数 | 1000 | 1000 | — |

有效性条件：

- Stage2 人工延迟：15 s；
- 插入加 Stage1-only 查询耗时：2.680 s；
- `stage1_only_window.valid = true`；
- 最终查询前 durable sequences 与 target sequences 在全部 5 个分片上一致；
- Stage2 finalization complete：true。

相比旧轮次的 100 个查询，本轮使用全部 1000 个新节点，统计波动明显更小。85.9% self-hit 的 Wilson 95% 区间约为 83.6%–87.9%；最终 100% 的区间约为 99.6%–100%。

两个质量指标回答不同问题：

- `self-hit@10` 是严格的新节点可达性测试。14.1% 的临时缺失仍不能描述为“完全没有质量损失”。
- `Top-10 overlap@10` 衡量 Stage1 与最终索引返回结果的整体变化。97.02% 表明平均每个 Top-10 结果集有 9.702 个结果保持一致，即整体查询结果只发生约 2.98% 的临时变化。

各分片内部连通、质心 home 和物理局部性确实让 Stage1 的整体结果较稳定，但它们不严格保证有限 beam/search budget 一定访问到查询自身的新节点。因此，当前最稳妥的论文结论是：

> Stage1 preserves 97.0% of the finalized Top-10 result set during the short asynchronous window, while strict self-discoverability improves from 85.9% to 100% after Stage2.

需要注明：该实验使用最终索引结果作为相对参考，不是基于动态 SIFT101M exact ground truth 的标准 Recall@10。

## 6. 动机实验四：Stage2 精度窗口持续时间

| 指标 | 结果 |
| --- | ---: |
| Stage2 finalized samples | 1128 |
| 平均 Stage2 延迟 | **136.42 ms** |
| P99 延迟直方图区间上界 | **512 ms** |
| P99 是否超过 30 s | 否 |
| 测量结束后的 backlog drain | 112.01 ms |
| 最终 remaining | 0 |
| Terminal failures | 0 |
| Retryable peer reverse attempts | 1 |

1128 个样本由 128 个预热更新和 1000 个正式测量更新组成。预热后开始窗口时，控制页尚未发布新的 warmup 快照，因此本轮 Stage2/locality 差分包含两部分；它们使用相同配置和执行路径，不影响对延迟量级和机制效果的判断，但正式论文中应在表注中说明样本数。

P99 的 512 ms 是直方图区间上界，不是精确的 512 ms 点估计。可以安全表述为：

> 99% of Stage2 tasks finish within the histogram bucket bounded by 512 ms, with an average delay of 136 ms and no terminal failure.

这表明 Stage1-only 的临时状态通常持续百毫秒量级，而不是秒级或分钟级。

## 7. 动机实验五：迁移对物理局部性的作用

| 指标 | Stage1 home | 最终迁移 home |
| --- | ---: | ---: |
| 最终边数 | 56,350 | 56,350 |
| 跨分片边数 | 10,106 | 8,058 |
| 跨分片边比例 | 17.93% | 14.30% |
| 绝对下降 | — | **3.63 个百分点** |
| 相对下降 | — | **20.27%** |

其他相关数据：

- 完成 Stage2 的节点：1128；
- 发生物理 home 迁移的节点：118，占 10.46%；
- 不需要迁移的 home match rate：89.54%；
- Stage2 failures：0。

只有约一成节点需要迁移，就将跨分片边数量从 10,106 降到 8,058，减少 2,048 条。这说明迁移不是无差别搬运，而是针对 home 不匹配节点进行选择性修复。

推荐论文表述：

> Mutation-boundary relocation migrates only 10.5% of finalized inserts, yet reduces their cross-shard edge ratio from 17.9% to 14.3%, a 20.3% relative reduction.

需要限定结论范围：当前 locality 统计针对本轮新完成 Stage2 的动态节点及其最终邻边，不是对整个 SIFT100M 静态基图重新扫描后的全图比例。

## 10. 局限性

1. 性能对照仅运行 1 次。最终论文建议至少重复 3 次，报告均值和误差条。
2. 质量指标是 self-hit 与相对 Top-10 overlap，不是动态 exact ground truth Recall@10。
3. P99 Stage2 延迟来自离散直方图，只能报告区间上界。
4. Locality 是本轮动态节点的边级统计，不是全索引扫描结果。
5. `system_variant.label` 在两个 JSON 中均显示为 profile 默认的 `baseline`，但 resolved update mode 分别正确为 `coupled` 和 `decoupled`；分析以 resolved mode 为准。
