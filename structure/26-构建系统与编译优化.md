# 第26课：构建系统与编译优化

## 学习目标
- 掌握CMake构建系统的完整配置
- 理解编译优化选项与条件编译
- 掌握storage-node-only构建配置

## 内容大纲

### 1. CMake配置一览
```cmake
# 项目类型
project(rdma-vamana CXX CUDA)          # 完整构建
project(rdma-vamana CXX)               # storage-node-only

# 标准
CXX: C++20, CUDA: C++17

# 编译选项
-Wall -Wextra -Wpedantic -Wfatal-errors  # 严格警告
-mavx2                                    # AVX2 SIMD
-ffast-math                               # 快速数学
-fcoroutines                              # C++20协程
-DNOHUGEPAGES                             # 禁用大页（开发模式）

# CUDA选项
--expt-relaxed-constexpr                  # 扩展constexpr
--expt-extended-lambda                    # 扩展lambda
-O3                                       # CUDA优化
CUDA_SEPARABLE_COMPILATION ON             # 分离编译
```

### 2. 构建目标
```cmake
# 主库
dvstor_runtime (STATIC)     — 核心运行时
dvstor_gpu_kernels (STATIC) — GPU内核库

# 可执行文件
dvstor                      — 统一服务（CN+MN）
dvstor_memory_node          — 仅MN
vamana_offline_builder      — 离线构建器
vamana_metis_repartitioner  — METIS重分区工具
dvstor_breakdown_benchmark  — 性能分解基准测试
```

### 3. 条件编译
```cmake
option(DVSTOR_STORAGE_NODE_ONLY "..." OFF)
option(DVSTOR_BUILD_EXECUTABLES "..." ON)
option(DVSTOR_BUILD_TESTS "..." ON)
option(DVSTOR_USE_NATIVE_ARCH "..." OFF)

# METIS可选支持
if (METIS_INCLUDE_DIR AND METIS_LIBRARY)
    set(DVSTOR_HAVE_METIS ON)
    target_compile_definitions(... PRIVATE DVSTOR_HAVE_METIS=1)
endif()
```

### 4. GPU架构自动检测
```cmake
if (NOT DEFINED CMAKE_CUDA_ARCHITECTURES)
    set(CMAKE_CUDA_ARCHITECTURES 80 86 89 90)
endif()
# 覆盖: A100(80), RTX 3090(86), RTX 4090(89), H100(90)
```

### 5. 三方依赖
```cmake
# nlohmann/json: header-only JSON库 (json.hh)
# cpp-httplib: header-only HTTP库 (httplib.h)
# xoshiro: header-only PRNG (xoshiro.hh)
# oneTBB: concurrent_queue, concurrent_vector
# Boost: program_options
```

### 6. 编译产物链接
```
dvstor:
  dvstor_runtime → dvstor_gpu_kernels + rdma_library
  rdma_library → libibverbs + pthread
  CUDA::cudart

vamana_offline_builder:
  rdma_library + dvstor_gpu_kernels + CUDA::cudart + METIS(可选)
```

### 7. 性能相关编译选项
```
Release构建: 默认-O2/-O3，无调试符号
Debug构建: -g -fno-omit-frame-pointer -fno-inline -fsanitize=address

DVSTOR_USE_NATIVE_ARCH=ON: -march=native (利用CPU全部指令集)
NOHUGEPAGES: 开发模式下避免需要root权限分配大页
```
