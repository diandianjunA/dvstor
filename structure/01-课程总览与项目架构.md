## 内容大纲

### 1. 项目定位
DVSTOR (Disaggregated GPU Vamana Index) 是一个存储-计算分离的GPU加速向量搜索基线系统：
- **核心算法**: Vamana图索引（单层有向图，Beam Search + RobustPrune）
- **加速硬件**: NVIDIA GPU（CUDA）用于距离计算和图剪枝
- **网络传输**: RDMA（Remote Direct Memory Access）跨节点读取远程向量数据
- **架构模式**: 存储节点（Memory Node）持有索引数据，计算节点（Compute Node）执行搜索/插入

### 2. 顶层目录结构
```
dvstor/
├── src/                    # 核心运行时源码
│   ├── common/             # 共享配置、类型定义、距离函数、工具类
│   ├── gpu/                # CUDA内核与GPU资源管理
│   ├── io/                 # 数据读写抽象
│   ├── http/               # HTTP服务接口
│   ├── memory_node/        # 存储节点实现（索引存储、插入、Peer通信）
│   ├── rdma/               # RDMA操作封装（读/写/原子操作）
│   ├── router/             # 多计算节点自适应查询路由
│   ├── service/            # 计算服务编排（ComputeService）
│   └── vamana/             # Vamana图索引核心实现
├── rdma-library/           # RDMA底层库（QP管理、内存注册、连接管理）
├── thirdparty/             # 第三方依赖（nlohmann/json, httplib, xoshiro）
├── tools/                  # 离线构建工具
│   ├── vamana_offline/     # 离线Vamana图构建器
│   └── breakdown_benchmark/# 性能分解基准测试
├── evaluation/             # 评估脚本（SIFT100M, SIFT1B）
├── reports/                # 性能报告与图表
└── CMakeLists.txt          # 构建系统配置
```

### 4. 构建系统
CMake C++20项目，关键构建选项：
- `DVSTOR_STORAGE_NODE_ONLY=ON`: 仅编译存储节点（无CUDA依赖）
- `DVSTOR_USE_NATIVE_ARCH=ON`: 使用`-march=native`
- `DVSTOR_METIS_PARTITION=ON`: 启用METIS图分区支持
- 编译产物：`dvstor`（计算节点）、`dvstor_memory_node`（存储节点）、`vamana_offline_builder`（离线构建器）

### 5. 技术栈
| 层次 | 技术 |
|------|------|
| 语言 | C++20 (协程, Concepts)、CUDA C++17 |
| 网络 | RDMA (libibverbs), TCP (元数据/控制) |
| 并发 | pthreads, oneTBB (concurrent_queue), std::coroutine |
| GPU | CUDA 11.8+, GPUDirect RDMA |
| 内存 | HugePage (2MB/1GB), 大页内存注册 |
| 构建 | CMake 3.18+, g++-12 |
