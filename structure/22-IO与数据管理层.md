# 第22课：IO与数据管理层

## 学习目标
- 理解`io::Database`的数据管理抽象
- 掌握索引元数据管理
- 理解数据读取与反序列化

## 内容大纲

### 1. Database抽象 (`io/database.hh`)
```cpp
template <typename T>
class Database {
    vec<T> data_;                // 所有向量连续存储
    u32 dim;                     // 向量维度
    u32 num_vectors_total;       // 向量总数
    u32 num_vectors_read;        // 已读向量数
    u32 max_slot;                // 最大槽位（路由场景）

    // 每个向量通过slot访问
    node_t get_id(size_t slot);
    span<T> get_components(size_t slot);
    void set_id(size_t slot, node_t id);
};
```
设计要点：
- 向量连续存储在`data_`中（`dim * num_vectors`个T元素）
- Slot机制支持路由场景中的动态查询入队
- 支持流式读取（`num_vectors_read` < `num_vectors_total`）

### 2. 数据读取 (`io/read_data.hh`)
支持的格式：
- `.fvecs` (float32): 4B dim + N×4B + float32数据
- `.bvecs` (uint8):  4B dim + N×4B + uint8数据
- `.ivecs` (int32):  4B dim + N×4B + int32数据

### 3. 反序列化 (`io/deserializer.hh`)
将磁盘格式转换为Database内部格式：
- 类型检测（auto模式）
- 量化编码（如果指定非float32存储类型）
- 大文件分块读取

### 7. 数据流
```
构建场景 (store_index=true):
  dataset → (在线构建) → Memory Node HugePage → store → .dat文件

加载场景 (load_index=true):
  .dat文件 → vmtouch/read → Memory Node HugePage → 就绪

在线场景 (store_index=false, load_index=false):
  dataset → Compute Node读取 → 在线构建 → Memory Node HugePage
```
