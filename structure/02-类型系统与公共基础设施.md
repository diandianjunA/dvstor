# 第2课：类型系统与公共基础设施

## 学习目标
- 掌握项目的核心类型定义与命名约定
- 理解配置系统的设计与参数管理
- 熟悉常量定义、距离函数、调试工具等公共模块

## 内容大纲

### 1. 核心类型定义 (`src/common/types.hh`)
```cpp
using node_t = u32;        // 节点ID类型
using element_t = f32;     // 向量元素类型
using distance_t = f32;    // 距离值类型
using filepath_t = std::filesystem::path;

template <typename T>
using hashset_t = std::unordered_set<T>;

template <typename K, typename V>
using hashmap_t = std::unordered_map<K, V>;
```
设计要点：
- 使用`u32`作为节点ID，支持最多42亿个向量
- `f32`距离和元素精度统一
- `hashset_t`/`hashmap_t`留有TODO注释，未来可替换为更快的容器

### 2. RemotePtr (`src/remote_pointer.hh`)
**核心设计**：64位压缩指针，编码跨节点的远程地址
```
[ 16位 Memory Node ID | 48位 Byte Offset ]
```
- `memory_node()`: 提取高16位获取节点ID
- `byte_offset()`: 提取低48位获取节点内偏移
- `is_null()`: `raw_address == 0` 表示空指针
- 支持`std::hash`（使用Murmur64哈希）用于`unordered_set`

### 3. 配置系统 (`src/common/configuration.hh`)
`IndexConfiguration`类使用Boost.ProgramOptions：
- **Vamana参数**: `R`（最大出度）、`beam_width`（搜索束宽）、`beam_width_construction`（构建束宽）、`alpha`（RobustPrune多样性因子）、`k`
- **GPU参数**: `gpu_device`、`gpudirect_rdma`
- **插入执行模式**: `compute`（计算节点执行）vs `storage_owner`（存储节点执行）
- **存储相关**: `storage_owner_batch_max`、`storage_owner_peer_rdma_tokens`等
- 兼容别名：`ef_search = beam_width`, `ef_construction = beam_width_construction`, `m = R`

### 4. 常量定义 (`src/common/constants.hh`)
```cpp
constexpr static u64 COMPUTE_NODE_MAX_MEMORY = 60ul * 1073741824ul;  // 60 GB
constexpr static u64 MEMORY_NODE_MAX_MEMORY = 260ul * 1073741824ul;  // 260 GB
constexpr static u32 MAX_QPS = 4;  // 每个计算节点最大QP数
constexpr static size_t CACHELINE_SIZE = 64;

// Vamana默认参数
constexpr static u32 DEFAULT_R = 64;
constexpr static u32 DEFAULT_BEAM_WIDTH = 128;
constexpr static u32 DEFAULT_BEAM_WIDTH_CONSTRUCTION = 200;
constexpr static f64 DEFAULT_ALPHA = 1.2;
constexpr static u32 GPU_BLOCK_SIZE = 512;
```

### 5. 距离函数 (`src/common/distance.hh`)
两套距离度量，均以模板策略模式实现：
- **L2Distance**: 欧几里得平方距离，使用AVX SIMD加速（`L2SqrSIMD16ExtAVX`）
- **IPDistance**: 内积距离 `1.0 - Σ(a[i] * b[i])`，同样有AVX版本
- 设计为策略类（`struct`含静态`dist`方法），使`ComputeService`和`Vamana`成为模板类

### 6. 向量数据类型 (`src/common/vector_dtype.hh`)
支持多种存储精度：
- `float32`: 32位浮点（默认）
- `uint8`: 8位无符号整数（量化存储）
- `int8`: 8位有符号整数（量化存储）
- 提供编解码函数：`encode_float_vector_to_storage` / `decode_storage_vector_to_float`

### 7. 其他公共设施
- `timing.hh/.cc`: 性能计时器
- `statistics.hh`: 线程统计（RDMA读/写字节数、距离计算次数等）
- `core_assignment.hh/.cc`: CPU核心绑定
- `debug.hh`: `dbg::print`条件调试输出
- `index_path.hh`: 索引文件路径解析
