# 第27课：评估脚本与实验流程

## 学习目标
- 理解evaluation目录下的实验脚本架构
- 掌握SIFT100M/SIFT1B评估流程
- 理解性能基准测试的工作方式

## 内容大纲

### 1. 评估目录结构
```
evaluation/
├── sift100m/
│   ├── README.md               — 实验说明
│   ├── sift100m_common.sh      — 公共配置
│   ├── prepare_sift100m_data.sh — 数据准备
│   ├── convert_sift100m.py     — 数据格式转换
│   ├── build_sift100m_index.sh  — 离线构建索引
│   ├── start_memory_node.sh    — 启动存储节点（单台）
│   ├── start_memory_node_[1-5].sh — 启动各存储节点
│   ├── start_all_memory_nodes.sh — 一键启动所有节点
│   ├── stop_memory_nodes.sh    — 停止所有存储节点
│   ├── run_recall.sh           — Recall测试
│   └── run_breakdown.sh        — 性能分解测试
└── sift1b/                     — 同上结构（10亿向量）
```

### 2. 公共配置 (`sift100m_common.sh`)
```bash
# 集群配置
COMPUTE_NODES=(...)    # 计算节点IP
MEMORY_NODES=(...)     # 存储节点IP
GPU_DEVICE=0

# Vamana参数
R=64
BEAM_WIDTH=128
BEAM_WIDTH_CONSTRUCTION=200
ALPHA=1.2
K=10
DIM=128

# 路径
DATA_PATH=/path/to/sift100m
INDEX_PREFIX=/path/to/index
```

### 3. 数据准备流程
```
下载 → 格式转换 → 上传到NFS
1. axel下载SIFT100M原始数据（.fvecs）
2. python convert_sift100m.py → 统一格式
3. 生成查询文件和groundtruth
4. 复制到所有节点可访问的共享存储
```

### 4. 索引构建
```bash
./evaluation/sift100m/build_sift100m_index.sh
# 内部调用:
./build/vamana_offline_builder \
    --data-path $DATA_PATH \
    --memory-nodes 5 \
    --partition-strategy bfs \
    --threads 32 \
    --R 64 --beam-width-construction 200 --alpha 1.2 \
    --output-prefix $INDEX_PREFIX
```

### 5. 集群启动
```bash
# 启动所有存储节点
./start_all_memory_nodes.sh
# 每个节点执行:
# ./build/dvstor_memory_node --server-index-file shard_N_of_5.dat ...

# 启动计算节点
./build/dvstor \
    --servers ${MEMORY_NODES[@]} \
    --load-index --index-prefix $INDEX_PREFIX \
    --dim 128 --threads 16 --coroutines 16 \
    --k 10 --beam-width 128
```

### 6. 性能测试
```bash
# Recall测试
./run_recall.sh
# 测量search recall@1/5/10

# 性能分解测试
./run_breakdown.sh
# 测量各阶段延迟分布

# 基准测试
./build/dvstor_breakdown_benchmark \
    --service-config config.ini \
    --workload mixed \
    --client-threads 16 \
    --read-ratio 0.5 \
    --warmup-seconds 30 \
    --measure-seconds 60
```
